# 🤖 AI 로컬 방문 기록 삭제기 (v1.5 내장형 SLM 구조 버전)

Ollama 같은 외부 프로그램을 개별 컴퓨터마다 설치할 필요가 없도록, 크롬 확장 프로그램 폴더 내부 및 브라우저 자체 자원만 사용하여 단독 구동하도록 설계된 **인-브라우저(In-Browser) AI 매크로** 패키지입니다.

## 📌 구조적 특징 (SLM 내장 방식의 메커니즘)
* **WebGPU / ONNX Runtime Web 아키텍처**: 외부 파이썬이나 Ollama 데몬 없이 크롬 브라우저가 직접 시스템의 그래픽카드 자원을 빌려와 자바스크립트 단에서 토큰을 연산합니다.
* **Hugging Face CDN 자동 동기화**: 수 기가바이트(GB)에 달하는 가중치(Weight) 바이너리 파일은 깃허브 업로드 용량 제한(파일당 최대 100MB) 및 확장 프로그램 패키지 용량 한계를 초과하므로, **최초 구동 시 Hugging Face 허브에서 브라우저 로컬 저장소(IndexedDB)로 모델을 자동 다운로드 및 캐싱**하도록 설계하는 것이 표준 프로덕션 아키텍처입니다.

## 🚀 사용 및 배포 방법 (GitHub 연동)
1. 본 압축 파일 안에 있는 3개의 파일(`manifest.json`, `popup.html`, `popup.js`)을 깃허브 저장소(Repository)에 그대로 올립니다.
2. 다른 컴퓨터에서 사용할 때는 깃허브에서 이 폴더를 다운로드합니다.
3. 크롬 주소창에 `chrome://extensions/`를 입력 후 **[개발자 모드]**를 켭니다.
4. **[압축해제된 확장 프로그램을 로드합니다]**를 눌러 해당 폴더를 등록하면, 다른 부가 설치 없이 그 즉시 브라우저 순정 AI 모드로 가동됩니다.
